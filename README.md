# ゆめぐも

「index.html」をブラウザで開くだけで遊べます。通信やインストールは不要です。

操作
- タップ: 寝ぼけてこちらを見る
- 短くなでる: 目がとろんとして、指を離すと眠る
- 長押しして動かす: 雲をつかんで移動する
- 仲間の上に置く: 下の子が少しむっとしたあと、一緒に眠る

撫でると少しだけ指へすり寄ります。短い撫でを続けると、くすぐったそうに一度だけ身をよじります。眺めている間にも、あくびが近い一匹へうつる、寄りかかって眠る、小さな星にきょとんとする、といった静かな反応があります。

画面上のボタン
- 増やす: 最大5匹まで増やす
- 戻す: 3匹に戻す
- 音: 初期状態はOFF
- 動き: 弱め / 停止

点数、勝敗、期限、課題はありません。健康効果を保証するものではありません。
